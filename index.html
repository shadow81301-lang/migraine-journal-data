個別品項與頭痛的關聯

根據你在「飲食記錄」裡輸入的每一道品項名稱計算——同一道菜吃過越多次、卻越常出現在頭痛前後，排名就會越前面。

以上統計已納入頭痛發生當天及前一天的紀錄（24–48 小時窗口），紀錄天數越多、吃過的次數越多，統計會越準確——這只是機率上的關聯，不是醫學診斷，仍建議跟醫生討論可疑的食物。

目前的儲存方式

每日蛋白質目標

設定目標後，「飲食記錄」會顯示今天累積吃了多少蛋白質、還差多少。可以先抓「體重(kg) × 1.6~2.2」估算運動族群的目標值。

連接 GitHub 同步

設定後，資料會存到你自己的 GitHub Repo，任何裝置只要填入一樣的設定就能看到同一份紀錄。這組設定只會存在「這個裝置的瀏覽器」裡，不會上傳到任何地方。

設定步驟

  1. 到 GitHub 建立一個新的 Repository（可以設成 Private），例如取名 migraine-journal-data。
  2. 進入該 Repo 的 Settings → Developer settings → Personal access tokens → Fine-grained tokens，建立一組新的 Token，Repository access 選「Only select repositories」並選這個 repo，Permissions 裡把 Contents 設為 Read and write。
  3. 複製產生的 Token（只會顯示一次），貼到上面的「Personal Access Token」欄位。
  4. 填好帳號、Repo 名稱、分支（預設 main），按「儲存並連接」。
  5. 之後在其他裝置（電腦／手機）打開同一個網頁，填入一樣的設定，就能看到同一份資料。

Token 相當於你 Repo 的鑰匙，請不要分享給別人，也不要貼在公開的地方。若擔心外洩，之後隨時可以到 GitHub 上把這組 Token 刪除、重新產生一組。

把這個網站放上 GitHub Pages

  1. 把這個檔案改名為 index.html，上傳到你剛建立的 Repo（或另一個公開的 Repo）根目錄。
  2. 到 Repo 的 Settings → Pages，Source 選擇 Deploy from a branch，Branch 選 main / root，儲存。
  3. 等一兩分鐘，GitHub 會給你一個網址，例如 https://yourname.github.io/repo名稱/，之後不管在手機還是電腦，打開這個網址就能使用。
